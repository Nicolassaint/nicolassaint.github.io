## Description

L'API OlympIA est une API que j'ai construite en utilisant FastAPI, vLLM et TEI. Elle permet aux agents du Ministère de l'Économie et des Finances d'interagir avec différents modèles d'IA open source fonctionnant sur le cluster GPU du Ministère.

## Impact

Cette API centralise l'accès aux modèles d'IA pour le Ministère, facilitant l'adoption de l'intelligence artificielle dans les applications processus métier tout en maintenant la souveraineté technologique grâce aux modèles open source.
