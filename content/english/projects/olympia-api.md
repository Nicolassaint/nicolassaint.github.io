## Description

OlympIA API is an API that I built using FastAPI, vLLM and TEI. It allows agents from the Ministry of Economy and Finance to interact with different open source AI models running on the Ministry's GPU cluster.

## Impact

This API centralizes AI model access for the Ministry, facilitating the adoption of artificial intelligence in applications and business processes while maintaining technological sovereignty through open source models.
